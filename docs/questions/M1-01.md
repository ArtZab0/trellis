# M1-01: fast-check or Effect's Arbitrary for CORE-01?

ADR-0001 and CORE-01 say property tests use fast-check. Effect 4 (ADR-0002) no longer integrates
with fast-check. It has its own `effect/Arbitrary` module, which builds generators directly from a
Schema, including its checks, and runs them with `runs`, `seed` and shrinking.

M1-01 uses `Arbitrary.checkEffect(Arbitrary.schema(Contract), …, { runs: 1000, seed: 20261125 })`.
That meets CORE-01's intent (1,000 runs, fixed seed, generated from the contract) but not its
wording ("fast-check").

Options:
1. Accept Effect's Arbitrary for schema-derived properties, and amend ADR-0001 to say so (fast-check
   stays for hand-written properties). Recommended: no second definition of each contract.
2. Write a Schema AST → fast-check translator. It must handle every schema construct used in the
   contracts and would be about 200 lines.

Note: Effect marks `Arbitrary` as `@stability unstable`.
